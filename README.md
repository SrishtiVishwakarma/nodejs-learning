# Node.js Learning

## Day 1 — Introduction to Node.js

### What I learned

- Node.js is a JavaScript runtime environment.
- Node.js was created by Ryan Dahl.
- Node.js uses Google's V8 JavaScript engine.
- Node.js allows JavaScript to run outside the browser.
- Node.js does not have browser objects like `window` and `document`.
- LTS means Long-Term Support and is generally preferred for stable development.
- npm (Node Package Manager) comes with Node.js and is used to install and manage packages.

### My understanding

Node.js allows JavaScript to run outside the browser. It uses the V8
engine to execute JavaScript and provides additional APIs that are
useful for server-side development.
